What is Swappiq?

Swappiq is a decentralized aggregation protocol that routes trades off-chain by default. It is designed to eliminate mempool exposure, reduce gas fees, and ensure price certainty. Instead of broadcasting trade data publicly, Swappiq operates on signed intent messages, which are privately quoted by solvers and only settled on-chain once confirmed.

Swappiq combines:

  • MEV protection through private RFQs
  • Multi-chain liquidity sourcing
  • Fallback logic for fail-safe trades
  • User-first economics and open infrastructure

Swappiq currently supports 48 EVM-compatible blockchain networks including major Layer 1s, Layer 2s, and emerging chains, making it the most comprehensive DEX aggregator available.

⚙️

How It Works

  1. User signs a trade intent off-chain (EIP-712 standard)
  2. Solvers return signed quotes with price, expiry, and path
  3. User selects and signs the preferred quote
  4. Both signatures are submitted via a relayer to the Swappiq smart contract
  5. The trade is executed atomically
  6. If execution fails, the fallback route is attempted or trade is cancelled

Key elements:

  • Solvers can include bots, market makers, or Swappiq-integrated wallets
  • Trade is valid only if both signatures match and expiration has not passed
  • Trades execute in 1–2 blocks

Why Off-Chain RFQ?

Public on-chain DEX trades expose user intent to bots. This leads to:

  • MEV extraction (sandwich attacks)
  • Slippage on final price
  • Gas waste on failed trades

Swappiq avoids this by:

  • Keeping orders private until fully signed
  • Enforcing quote commitment with EIP-712
  • Only submitting confirmed trades to the blockchain

Result:

  • 500ms–3s response time
  • No slippage after quote acceptance
  • Guaranteed price finality

Fallback Safety System

  • Fallback triggers auto-routing to Uniswap or other verified on-chain paths
  • All fallback paths run slippage check + expiry
